Merapi Sky Run: a golden-hour island flight game. Fly a propeller plane off a coastal runway, thread ten glowing rings around a volcano, then bring her home to the strip — with a lit instrument panel, fuel to manage, stalls, and a landing that only counts if it is gentle, lined up, and on the gear.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard: W/S or arrows to pitch, A/D to bank and turn, Shift/Ctrl for throttle, G gear, F flaps, Space brake, P pause, R restart. The mouse steers too.
